# Offline Local Observable AI Training

This example demonstrates the core concepts of an offline, local, and observable AI workstation. It simulates a simple linear regression model that generates its own synthetic data, trains entirely on the local machine without any external network access, and provides basic observability into its training process and predictions.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Open a terminal or command prompt in the same directory.
3. Run the script using `python main.py`.
